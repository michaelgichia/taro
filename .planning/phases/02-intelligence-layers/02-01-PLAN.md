<task type="auto">
  <name>Create click deduplicator</name>
  <files>src/parser/steps/deduplicator.ts</files>
  <action>
    Create src/parser/steps/deduplicator.ts that:
    - Exports function deduplicateSteps(steps: RecordingStep[]): RecordingStep[]
    - Detects rapid clicks (<500ms) on same selector
    - Keeps only the first click when duplicates detected
    - Preserves click order for non-duplicate clicks
    - Handles edge case: clicks on different elements are NOT deduplicated
    - Types: Import RecordingStep from ../types.ts (created in Phase 1)

    Algorithm:
    1. Iterate through steps in order
    2. For each click step, look ahead up to 500ms
    3. If matching selector found, mark as duplicate
    4. Return filtered list preserving original order
  </action>
  <verify>npm test -- --grep "deduplicate" passes</verify>
  <done>deduplicateSteps(clickSteps) returns single click for rapid duplicates</done>
</task>

<task type="auto">
  <name>Create noise event filter</name>
  <files>src/parser/steps/noise-filter.ts</files>
  <action>
    Create src/parser/steps/noise-filter.ts that:
    - Exports function filterNoiseSteps(steps: RecordingStep[]): RecordingStep[]
    - Filters out: dblClick events, mousemove/mouseover/mouseout (cursor wandering)
    - Filters out: scroll events without user intent (rapid scroll without action)
    - PRESERVES: click, fill, select, change, navigate, keyPress, assert
    - Adds metadata to kept steps: { isNoiseFiltered: true }
    - Returns original step array if nothing filtered (no mutation)

    Criteria for scroll filtering:
    - Scroll that has an action within 2s after is NOT noise (user scrolled to find something)
    - Scroll that has NO action within 2s IS noise (accidental scroll)
  </action>
  <verify>npm test -- --grep "filterNoise" passes</verify>
  <done>filterNoiseSteps removes dblClick, cursor events, accidental scrolls</done>
</task>
