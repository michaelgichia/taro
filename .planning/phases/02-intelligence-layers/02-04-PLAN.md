<task type="auto">
  <name>Create dialog flow detector</name>
  <files>src/parser/steps/dialog-detector.ts</files>
  <action>
    Create src/parser/steps/dialog-detector.ts that:
    - Exports function groupDialogSteps(steps: RecordingStep[]): DialogFlow[]
    - Detects dialog patterns:
      - Open dialog: click on modal trigger → dialog appears
      - Fill dialog: fill form fields in dialog
      - Submit dialog: click submit/confirm in dialog
      - Close dialog: click close/ESC/cancel outside
    - Groups related steps into DialogFlow:
      interface DialogFlow {
        id: string;
        type: 'modal' | 'drawer' | 'popover' | 'confirm' | 'form';
        triggerStep: RecordingStep;
        contentSteps: RecordingStep[];
        closeStep?: RecordingStep;
        assertionStep?: RecordingStep;
      }

    Detection heuristics:
    - Click followed by appearance of modal-like selector → open
    - Multiple fills in quick succession after open → form fill
    - Click on .close, [aria-label="Close"], or ESC → close
    - Assertion on dialog content → verification

    Time window: related steps within 30s are grouped
  </action>
  <verify>npm test -- --grep "dialog" passes</verify>
  <done>groupDialogSteps returns DialogFlow[] with grouped steps</done>
</task>
