  <action>
Create src/core/scorer.ts with the following functions:

1. **calculateQueryScore(queryResults: QueryResult[])**:
   - Weights: getByRole=1.0, getByLabelText=0.8, getByText=0.6, getByPlaceholderText=0.5, getByTestId=0.2
   - Returns 100 if empty array
   - Returns weighted average * 100

2. **calculateAssertionScore(code: string)**:
   - Strong matchers (1.0): toHaveValue(), toBeChecked(), toHaveTextContent(), toBeVisible()
   - Weak only (0.3): toBeInTheDocument() without any strong matcher
   - Count strong vs weak assertions using regex
   - Return percentage of strong assertions

3. **calculateStructureScore(code: string)**:
   - Base: 50
   - +20 if describe() present
   - +15 per additional it() block (cap at +30)
   - -20 penalty for single monolithic it() > 2000 chars
   - Clamp to 0-100

4. **calculateAggregateScore(dimensions: ScoreDimensions)**:
   - Weighted: 40% query + 35% assertions + 25% structure
   - Grade: A>=90, B>=80, C>=70, D>=60, F<60

5. **scoreGeneratedTest(code: string, queryResults?: QueryResult[])**:
   - Calls all three calculate functions
   - Returns ScoreResult with total and grade

Use picocolors for console output formatting.
