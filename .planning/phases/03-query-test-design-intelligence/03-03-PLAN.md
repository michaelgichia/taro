**`buildQuery(info: ElementInfo, selector: string): QueryResult`:**

Use the ARIA role map and priority decision tree from RESEARCH.md Pattern 4:

```typescript
const ROLE_MAP: Record<string, string> = {
  button: 'button', a: 'link', input: 'textbox',
  select: 'combobox', textarea: 'textbox',
  h1: 'heading', h2: 'heading', h3: 'heading',
  h4: 'heading', h5: 'heading', h6: 'heading',
  img: 'img',
}
```

Priority order (immutable logic — return first match):
1. `impliedRole = info.role ?? ROLE_MAP[info.tagName]`, `accessibleName = info.ariaLabel ?? info.innerText` → if both truthy: `getByRole(impliedRole, { name: accessibleName })`, quality `'excellent'`
2. `info.ariaLabel` truthy (no role match): `getByLabelText(ariaLabel)`, quality `'excellent'`
3. `info.innerText` truthy: `getByText(innerText)`, quality `'good'`
4. `info.placeholder` truthy: `getByPlaceholderText(placeholder)`, quality `'acceptable'`
5. Fallback: sanitize selector → `getByTestId(sanitized)`, quality `'fragile'`

Selector sanitization for testId: `selector.replace(/[^a-zA-Z0-9-]/g, '-').replace(/^-+|-+$/g, '')`

**`selectMatcher(info: ElementInfo, action: string): string`:**

Check in order (immutable if-chain):
1. `info.type === 'checkbox'` → `'.toBeChecked()'`
2. `info.value !== undefined && action === 'fill'` → `` `.toHaveValue('${escapeSingleQuote(info.value)}')` ``
3. `action === 'assert' && info.innerText` → `` `.toHaveTextContent('${escapeSingleQuote(info.innerText)}')` ``
4. `action === 'assert' && info.role === 'dialog'` → `'.toBeVisible()'`
5. Default: `'.toBeInTheDocument()'`

**`inspectElement(url: string, cssSelector: string, timeoutMs = 5000): Promise<ElementInfo | null>`:**

Implementation from RESEARCH.md Pattern 3. Key requirements:
- `chromium.launch({ headless: true })`
- `page.goto(url, { timeout: timeoutMs, waitUntil: 'domcontentloaded' })`
- `locator.evaluate((el: Element) => ({ ... }))` extracting all ElementInfo fields
- Wrap entire function body in `try/catch` returning `null` on ANY error (timeout, DNS failure, element not found)
- Always `browser.close()` in `finally` block
- On failure: emit `pc.yellow('[tayo] QRY-02:')` warning with URL and selector to console

**`inspectElements(url: string, selectors: string[], timeoutMs = 5000): Promise<Map<string, ElementInfo | null>>`:**

Batch version — launches browser ONCE, reuses one page for all selectors (fixes Pitfall 3):
- Launch browser once
- For each selector: navigate to URL (already on page if same URL), evaluate locator
- Return `Map<cssSelector, ElementInfo | null>`
- On individual selector failure: set map value to `null`, continue (don't fail all)
- Always close browser in `finally`

```typescript
export function emitQry03Warning(selector: string): void {
  const pc = picocolors
  console.warn(
    pc.yellow('[tayo]') +
    pc.dim(' QRY-03:') +
    ` No accessible query for ${pc.bold(selector)} — consider adding aria-label or data-testid to this element`
  )
}
```
