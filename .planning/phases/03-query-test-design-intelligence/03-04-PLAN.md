**`findTestFiles(root: string): Promise<string[]>`:**

Recursive directory walk using `readdir(dir, { withFileTypes: true })`:
- Skip directories named: `node_modules`, `.git`, `dist`, `.tayo`, `coverage`, `.next`, `.nuxt`
- Match files by regex: `/\.(test|spec)\.(ts|tsx|js|jsx)$/`
- Return array of absolute paths
- No mutation (use spread/concat instead of push to a mutable array — or use a results array that only grows via push to the local variable, not to a shared mutable closure)

**`analyzeTestFile(filePath: string): Promise<ConventionFile>`:**

Internal helper. Read file content, analyze WITHOUT Babel (string-based detection is sufficient and faster — no need to parse AST for convention detection):
- `importStyle`: `content.includes('require(')` → 'cjs', else 'esm'
- `hasDescribeBlock`: `content.includes('describe(')` → boolean
- `mockPattern`: `content.includes('vi.mock(')` → 'vi.mock'; `content.includes('jest.mock(')` → 'jest.mock'; else 'none'
- `hasHelperWithExpect`: detect helper function (non-test function containing expect): use regex to find function declarations or arrow functions that contain `expect(` but are NOT inside an `it(` or `test(` block — simplified detection: any line with `expect(` that is inside a standalone function (search for `function [a-z]` or `const [a-z]+.*=.*=>` followed later by `expect(` before the closing brace). Use a simpler heuristic: does the file contain `expect(` outside of an `it(`/`test(` block? Search for lines with `expect(` that are not immediately inside `it(`/`test(`/`describe(` — for phase 3, emit warning if `hasHelperWithExpect` is true based on string heuristics (false positives acceptable; exact AST analysis is deferred)
  - Simple implementation: `hasHelperWithExpect = content.includes('expect(') && /function\s+[a-z]/.test(content)`

**`deriveConventions(files: ConventionFile[], projectRoot: string): ConventionsSchema`:**

Internal pure function (no I/O). From the array of ConventionFile:
- `importStyle`: majority vote (count esm vs cjs, pick winner; default 'esm' on tie)
- `mockPattern`: if any file has vi.mock → 'vi.mock'; if any has jest.mock → 'jest.mock'; else 'none'
- `folderPattern`: if all test files are in `__tests__/` dirs → '__tests__'; if all are colocated (no `__tests__`) → 'colocated'; mixed → 'mixed'; empty → 'unknown'
- `fileExtension`: majority of extensions among found test files; default 'ts'
- `scannedAt`: `new Date().toISOString()`
- `projectRoot`

Return immutable ConventionsSchema object.

**`readConventions(projectRoot: string): Promise<ConventionsSchema | null>`:**

Try to read `{projectRoot}/.tayo/conventions.json`:
- If exists: `JSON.parse(content)` and return as `ConventionsSchema`
- If ENOENT: return `null`
- Other errors: return `null` (don't crash CLI)

**`scanConventions(projectRoot: string): Promise<ConventionsSchema>`:**

Full scan pipeline:
1. `const files = await findTestFiles(projectRoot)`
2. If zero files found: log `pc.yellow('[tayo] CTX: No test files found — using defaults')`, build defaults with `{ ...DEFAULT_CONVENTIONS, projectRoot, scannedAt: new Date().toISOString() }`, persist to `.tayo/conventions.json`, return
3. `const analyzed = await Promise.all(files.map(analyzeTestFile))`
4. `const conventions = deriveConventions(analyzed, projectRoot)`
5. Persist: `mkdir(.tayo/, { recursive: true })` then `writeFile(.tayo/conventions.json, JSON.stringify(conventions, null, 2), 'utf-8')`
6. Emit TEST-02 warnings for any helper-with-expect files: `pc.yellow('[tayo] TEST-02: Helper function with expect() found in ...')`
7. Return `conventions`
